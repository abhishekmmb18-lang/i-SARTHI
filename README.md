# iSARTHI
iSARTHI is an AI-powered road intelligence and vehicle safety platform that transforms vehicles into sensing units. Combining YOLOv8 computer vision, IoT sensors, GPS/GIS, Edge AI, and V2V communication, it detects potholes, road damage, obstacles, and waterlogging, enabling real-time hazard alerts, AI fleet insights, and infrastructure monitoring.

## Repository Modules
- **Goverment Dashboard**: Real-time government and departmental monitoring command center for MoRTH, NHAI, State PWD, and Municipal Corporations. Features live sensor telemetry ingestion, alert date & time tracking, GIS hotspot mapping, and civil repair work orders.
